# Tasks: Accounts, roles, sharing & live collaboration

**Input**: Design documents from `specs/005-accounts-sharing-collab/`
**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/http-api.md, contracts/ui.md, quickstart.md

**Tests**: required by the constitution (IV): Vitest at the server seams (auth, permissions, Hocuspocus), Playwright for every acceptance scenario on Chromium, Firefox and WebKit, with several browser contexts for anything collaborative. E2E runs with the test sign-in bypass (`OVERTREE_TEST_AUTH=1`, research R4); a `clerk` Playwright project runs the smoke set against the real Clerk dev instance.

**Order**: phases follow the requested order (sign-in → admin → dashboard → sharing → per-file → live presence), not the spec's priority numbers. Spec story ↔ phase: US1 sign-in (P3), US5 admin (P4), US2 dashboard (P5), US3 sharing (P6), US6 per-file (P7), US4 live (P8).
